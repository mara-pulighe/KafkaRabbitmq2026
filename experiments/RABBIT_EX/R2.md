# R2 – Multiple Message Delivery

## Objective

Verify RabbitMQ's ability to reliably deliver multiple messages published to the same queue.

## Procedure

1. Start the RabbitMQ infrastructure.
2. Publish a sequence of messages to the queue using the producer application.
3. Start the consumer and allow it to process all available messages.
4. Observe message reception and ordering.


## Related Concepts

- Reliable Message Delivery
- FIFO Ordering
- Queue-Based Communication
- Asynchronous Messaging
