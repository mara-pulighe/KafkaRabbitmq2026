# R3 – Multiple Consumers

## Objective

Verify RabbitMQ's ability to distribute messages among multiple consumers connected to the same queue.

## Procedure

1. Start the RabbitMQ infrastructure.
2. Launch multiple consumer instances connected to the same queue.
3. Publish a sequence of messages using the producer application.
4. Observe how messages are assigned to consumers.


## Related Concepts

- Work Queue Pattern
- Load Distribution
- Scalability
- Asynchronous Messaging
