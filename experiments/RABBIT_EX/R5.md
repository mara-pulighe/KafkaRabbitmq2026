# R5 – Message Recovery After Consumer Failure

## Objective

Verify RabbitMQ's ability to recover from consumer failures and prevent message loss through message acknowledgements.

## Procedure

1. Start the RabbitMQ infrastructure.
2. Publish one or more messages to the queue.
3. Start a consumer and allow it to receive a message.
4. Interrupt the consumer before it acknowledges the message.
5. Restart the consumer.
6. Observe message delivery after reconnection.


## Related Concepts

- Message Acknowledgements
- Message Redelivery
- Consumer Recovery
- Fault Tolerance
- Reliable Message Delivery
