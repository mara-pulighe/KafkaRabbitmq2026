# R1 – Asynchronous Messaging and Temporal Decoupling

## Objective

Verify that RabbitMQ supports asynchronous communication by allowing producers and consumers to operate independently in time.

## Procedure

1. Start the RabbitMQ infrastructure.
2. Execute the producer while no consumer is active.
3. Verify through the RabbitMQ Management UI that the message is available in the queue.
4. Start the consumer after a delay.
5. Observe message delivery.

- Asynchronous Communication
- Temporal Decoupling
- Message-Oriented Middleware
