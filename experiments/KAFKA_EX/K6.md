# K6 – Event Replay

## Objective

Verify Kafka's ability to replay previously consumed events by resetting consumer offsets.

## Procedure

1. Start the Kafka infrastructure.
2. Publish a sequence of events to a topic.
3. Consume all available events.
4. Reset the consumer group's offsets to an earlier position.
5. Restart the consumer.
6. Observe event consumption after the offset reset.
