# K5 – Event Persistence and Consumer Offsets

## Objective

Investigate Kafka's persistence model and the role of consumer offsets in tracking event consumption.

## Procedure

1. Start the Kafka infrastructure.
2. Create or select a Kafka topic.
3. Publish a sequence of events to the topic.
4. Start a consumer belonging to a consumer group and observe the received events and their offsets.
5. Stop the consumer and start another consumer using a different group ID, with auto_offset_reset set to earliest.
6. Verify that the second consumer group can read the previously published events without republishing them.

- Distributed Logs
