# K1 – Basic Producer–Consumer Communication

## Objective

Verify successful communication between Kafka producers and consumers through a topic.

## Procedure

1. Start the Kafka infrastructure.
2. Create or select a Kafka topic test_topic.
3. Start a consumer subscribed to the topic.
4. Execute the producer and publish one or more events.
5. Observe event reception by the consumer.
