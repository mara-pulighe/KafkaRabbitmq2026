# K8 – Consumer Failure Recovery

## Objective

Verify Kafka's ability to recover from consumer failures while preserving processing progress through offset management.

## Procedure

1. Start the Kafka infrastructure.
2. Publish a sequence of events to a topic.
3. Start a consumer belonging to a consumer group.
4. Allow the consumer to process some events.
5. Interrupt the consumer.
6. Restart the consumer.
7. Observe consumption behaviour after recovery.
