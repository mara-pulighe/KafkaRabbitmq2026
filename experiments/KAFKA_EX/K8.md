# K8 – Consumer Failure Recovery

## Objective

Verify Kafka's ability to recover unprocessed events after a consumer failure using committed consumer offsets.

## Procedure

1. Start the Kafka infrastructure.
2. Publish a sequence of events to a topic.
3. Start a consumer belonging to a consumer group with automatic offset commits disabled.
4. Allow the consumer to process and commit the first event.
5. Interrupt the consumer while processing the next event, before its offset is committed.
6. Restart the consumer using the same consumer group.
7. Verify that the interrupted event is consumed again and previously committed events are not reprocessed.
