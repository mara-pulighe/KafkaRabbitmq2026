# K3 – Multiple Consumers (Single Partition)

## Objective

Verify how Kafka distributes events among multiple consumers belonging to the same consumer group when the topic contains a single partition.

## Procedure

1. Start the Kafka infrastructure.
2. Create a topic with a single partition.
3. Launch multiple consumers belonging to the same consumer group.
4. Publish a sequence of events to the topic.
5. Observe consumer activity.


## Related Concepts

- Consumer Groups
- Partitions
- Partition Assignment
- Parallel Message Processing
- Event Streaming

## Reference Files

- `producer_multi_partition.py` 
- `consumer_multi_partition.py`

## Topic Configuration
kafka-topics.sh --create \
  --topic test_topic_multi \
  --bootstrap-server localhost:9092 \
  --partitions 1 \
  --replication-factor 1
