# K4 – Multiple Consumers with Multiple Partitions

## Objective

Verify Kafka's ability to distribute workload across multiple consumers through partition-based parallelism.

## Procedure

1. Start the Kafka infrastructure.
2. Create a topic containing multiple partitions.
3. Launch multiple consumers belonging to the same consumer group.
4. Publish a sequence of events to the topic.
5. Observe partition assignment and consumer activity.


## Related Concepts

- Consumer Groups
- Partitions
- Partition Assignment
- Parallel Processing
- Scalability

## Reference Files

- `multiple_messages_producer.py` 
- `consumer_multi_partition.py`

## Topic Configuration
kafka-topics.sh --create \
  --topic test_topic_multi \
  --bootstrap-server localhost:9092 \
  --partitions 3 \
  --replication-factor 1
