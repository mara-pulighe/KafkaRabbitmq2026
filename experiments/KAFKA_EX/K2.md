# K2 – Multiple Messages

## Objective

Verify Kafka's ability to store and deliver multiple events published to the same topic.

## Procedure

1. Start the Kafka infrastructure.
2. Create or select a Kafka topic.
3. Publish a sequence of events using the producer application.
4. Start a consumer subscribed to the topic.
5. Observe event reception.


## Related Concepts

- Event Streaming
- Topic-Based Communication
- Event Persistence
- Reliable Event Delivery
